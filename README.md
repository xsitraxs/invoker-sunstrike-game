# Sun Strike — тренажёр ульты Инвокера

Одностраничный браузерный тренажёр на **упреждение точки каста Sun Strike**.
Ровно один файл — `index.html` (HTML + CSS + ванильный JS, canvas 2D, WebAudio).
Без сборщиков, без библиотек, без ассетов и **без единого запроса в сеть**:
открывается двойным щелчком по файлу и работает офлайн (в том числе с телефона).

```
клик по index.html → «НАЧАТЬ РАУНД» → бей туда, где цель будет через 1.7 с
```

## Зачем это

У Sun Strike есть подвох: каст выглядит мгновенным, но урон приходит **ровно через
задержку** (по умолчанию 1.7 с — как в доте). Значит целиться надо не в текущую
позицию цели, а **в точку, где она окажется в момент удара**. Тренажёр даёт:

* визуально мгновенный каст (~0.3 с) и пульсирующий «кипящий» маркер, который
  взрывается столбом света через задержку;
* **разбор каждого каста**: на 1 секунду появляются две метки — куда ты кликнул и
  где цель была в момент удара, вектор ошибки и подпись вида
  `MISS 175 px · отставание` + `УПРЕЖДАЙ БОЛЬШЕ: смести точку на ~175 px вперёд по курсу`;
* хитмап смещений за всю историю (перелёт / отставание / боковой снос) с текстовым выводом;
* XP/уровни и рекорды в `localStorage`.

## Управление

| Действие | Мышь / клавиатура | Тач |
|---|---|---|
| Каст Sun Strike | ЛКМ по точке | тап по точке |
| Пауза | ПКМ / `Space` / `Esc` | кнопка ⏸ в HUD |
| Рестарт раунда | `R` | кнопка «ЕЩЁ РАЗ» |
| Сложность | `1`–`4` | карточки в меню |
| Звук | `M` | кнопка 🔊 в HUD |

Мультитач не плодит касты: работает только первый активный палец. Тап-метки
исчезают через полсекунды, чтобы не заслонять арену.

## Сложности

| # | Название | Что делает |
|---|---|---|
| 1 | **Разминка** | 2 крипа, прямые траектории, медленно, увеличенный радиус |
| 2 | **Норма** | 2 героя + крип: джуки, остановки, рывки, средняя скорость |
| 3 | **Хард** | быстрые герои, частые смены курса, края карты в тумане войны |
| 4 | **Insane** | stutter-step, блинки на ~300 px, джуки, три быстрых цели |

Крипы всегда идут по маршруту (по ТЗ), герои «живут»: боковые джуки, развороты,
стойки на 0.5–1 с, рывки, телепорт-блинки (только Insane).

## Что считается и показывается

HUD во время раунда: время, касты, попадания, точность, стрик, средний промах, киллы, очки.

Экран итогов: точность, киллы, касты, попадания, лучший стрик, **средний промах**,
**средняя ошибка**, **систематический снос по курсу** (+ перелёт / − отставание),
**боковой снос**, ошибка во времени, очки, уровень и XP за раунд, рекорды,
**график ошибки по ходу раунда** и **хитмап смещений**.

Хитмап (меню и итоги) копит все выстрелы в виде `(along, perp)`:

* по горизонтали — **по курсу цели**: влево отставание, вправо перелёт;
* по вертикали — боковой снос;
* зелёные точки — попадания, красные — промахи, жёлтый крест — центроид
  (систематический снос) + разброс (σ).

Под графиком — текстовый вердикт: «ты **ПЕРЕупреждаешь** … убавляй упреждение
примерно на N px» или «ты **НЕДОупреждаешь** … добавляй N px».

## Настройка под себя

В меню:

* **Задержка урона** — слайдер 1.0–2.5 с (1.0 — паблик с низким пингом,
  2.5 — тренировка длинного упреждения). Настройка сохраняется.
* **Длительность раунда** — 30 / 60 / 120 с.

Всё остальное — в объекте `CONFIG` в начале скрипта (комментарии на русском):

| Ключ | За что отвечает |
|---|---|
| `CONFIG.strike.delayDefault / radius / hitboxMul / castAnim / castCooldown` | задержка урона, радиус зоны, прощение хитбокса, анимация, КД каста |
| `CONFIG.unit.*` | HP, радиусы тел, скорости, тайминги джуков/стоек/рывков/блинков |
| `CONFIG.lanes.*` | число дорожек, их Y/X-узлы, ширина, минимальная дистанция между целями |
| `CONFIG.field.*`, `CONFIG.lanes.maxAspect` | геометрия игрового поля и отступы |
| `CONFIG.guide.*` | тренажёрная подсказка: линия курса и маркер «цель будет здесь через N с» |
| `CONFIG.score.*` | очки, бонусы за скорость и попадание в центр, шаг множителя, XP |
| `CONFIG.fx.*` | dpr, лимиты частиц и волн, тряска, вспышки, подписи, следы |
| `CONFIG.heatmap.*` | сколько выстрелов хранить и какой масштаб ошибки у хитмапа |
| `DIFFICULTIES` | таблица сложностей целиком (скорости, вероятности поведений, туман, радиус) |

Масштаб: все параметры заданы в «дизайн-px» (как будто экран 1280×720) и умножаются
на общий масштаб `S`, который считается от размера окна. Поэтому на телефоне карта,
радиус удара и скорости остаются теми же *относительно* экрана.

## Производительность

* один `requestAnimationFrame` с дельта-таймингом, кламп `dt ≤ 50 мс`;
* земля, дорожки и туман рендерятся **один раз** при ресайзе в offscreen-canvas,
  на кадре — только `drawImage`;
* лимиты частиц/волн/маркеров, кэш шрифтовых измерений не нужен;
* тряска экрана сдвигает кадр **только целыми пикселями** (дробный сдвиг заставляет
  браузер пересэмплировать всю землю каждый кадр — главный источник фризов);
* авто-деградация: ниже 48 FPS — `dpr=1`, без подписей и следов, меньше частиц;
  ниже 42 FPS — минимальный режим (мало частиц, без затемнения столба света);
* в браузере игре не нужны ни сеть, ни таймеры: после загрузки внешних запросов нет.

## Проверка

Логика развязана с DOM (внешний слой — только события и канвас), поэтому её можно
прогонять headless. Во время разработки использовались три проверки:

1. **Headless-прогон** (заглушки DOM/Canvas): бот играет раунды на всех сложностях,
   проверяются прямой килл, респавн, пауза (время не течёт), ресайз в портрет,
   отсутствие юнитов вне поля, 120-секундный марафон на Insane без исключений.
2. **Текстовая проверка**: снимаем реальные подписи сетки статистики, итогов,
   рекордов и вердиктов хитмапа — проверяем формулировки «перелёт/отставание».
3. **Рендер кадров в PNG** (`@napi-rs/canvas`): смотрим глазами меню, маркер запала,
   взрыв, разбор промаха, туман на Харде, Insane, портрет/ландшафт телефона.
