# HoI4 Performance Mod (рабочее название)

Экспериментальный проект для Hearts of Iron IV. Цель — исследовать возможности ускорения симуляции, особенно в поздней игре, по возможности сохраняя игровой процесс.

**Статус: ранний каркас. Оптимизаций и результатов бенчмарков пока нет.** Прирост производительности не подтверждён. Мод не опубликован; совместимость ни с одной версией игры и ни с одним другим модом не проверена.

## Планы, а не реализованные функции

После получения файлов соответствующей версии игры и базовых замеров планируется исследовать скрипты и возможные источники нагрузки. Изменения ИИ, числа дивизий и поведения игры не реализованы; любые такие предложения потребуют отдельного описания последствий и согласования. Выбор кандидатов будет основан на аудите, а эффект — на измерениях, не на предположениях.

## Тестирование и совместимость

Для безопасной работы нужны точная версия игры и checksum, DLC и другие моды, целевая конфигурация совместимости, сведения о компьютере, сохранение и возможность замеров, а также доступ к нужным файлам установленной игры. Инструкции по их поиску и заполнению — в [методике](docs/BENCHMARKS.md). Исходные файлы установленной игры не изменяются.

`descriptor.mod` и шаблон `docs/hoi4_perf_mod.mod.template` — заготовки, не подтверждение совместимости или проверенной установки. По запросу пользователя в поле `supported_version` указано `1.19.4.*`; это целевая маркировка, а не подтверждение совместимости. Соответствие маркировки поведению лаунчера и работа мода на этой версии ещё не проверены. На текущем этапе устанавливать мод для ускорения бессмысленно: изменений игры нет.

## Правовая оговорка

Это неофициальный проект, не связанный с Paradox Interactive. Не публикуйте неизменённые файлы игры без проверки прав на их распространение. При подготовке релиза исключайте `.git`, локальные сохранения, логи и другие служебные файлы.
